# 语义区间英文语音编辑

语义区间英文使用与词形发音一致的文本输入、整体试听和语音编辑入口。
保留 name_en 纯文本，新增可选 name_en_rich 与 voice_profile 保存标注及发音人设置。
旧草稿缺少新字段时正常读取；新字段随草稿保存和重新打开完整保留。
富文本正文必须与 name_en 一致，并遵守现有富文本和发音配置校验。
不改变中文名称、200 字符限制和既有词义结构。
发布前需拆出兼容契约补丁：先更新前端响应 schema，再更新后端，最后开放新编辑入口。当前完整候选前端向旧 API 写新字段会被拒绝，不支持直接前端先发布。
验收：`cargo test --lib sense_group_voice`
