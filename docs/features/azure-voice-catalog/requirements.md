# 音色目录与 C 端音频选择

- 音色目录只读本地数据库，不在页面请求中调用 Azure 或同步数据。
- 后端预置当前已核对的 73 个英美音色，8 个标为常用；其余仍返回并放入默认折叠的“更多音色”。
- 展示友好名称，常用音色带中英文名；内部继续使用稳定 alias。
- 未配置时所有 checkbox 默认 false；仅恢复已有的明确选择，不随目录新增自动勾选。
- 勾选保存为未来向 C 端提供哪些音色音频的配置；试听不改变勾选，也不代表 C 端音频已就绪。
- 常用/非常用音色都可选，折叠不会丢选择。
- 当前发布只保留 voice_profile；自动为 C 端生成音频的任务尚未实现，不在本次界面修正中隐式新增。
- 保留历史 ID、alias、人工停用与限幅；显式维护命令更新 Azure 能力。
- 更新隔离本地预览，不部署测试环境。

验收：`SQLX_OFFLINE=true cargo test --locked --all-features --test speech_voice_catalog_seed`
