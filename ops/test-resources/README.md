# 临时测试资源

主记录和测试清理操作在前端仓库 [test-resource-isolation](https://github.com/LonelyFellas/tsz/blob/main/docs/features/test-resource-isolation/README.md)。

配置见根 `.env.example` 的 `TEST_RESOURCES_*`。未配置时不开放测试请求头；配置必须完整且至少有一个明确的管理员/用户 ID，两个身份域分别校验。测试 bucket 为 `tshb-test-assets`，root 为 `/temporary-tests`，不能由请求或环境变量改成普通目录。

支持语音试听、管理员音频、头像及认证材料图片。新建测试资源时必须提供有效测试头；批次联合验收的写请求也需要提供该头。持久化 key 自带批次与空间，读取和后台回收依该 key 选择测试存储。确认从测试暂存生成的文件时保留源批次，即使重试丢失请求头也不能写入普通目录。普通/测试和不同测试批次之间禁止复制；其余业务权限保持原规则。

同一批次的试听缓存独立于普通缓存和其他批次。词条、独立例句、正式配音和试听的联合验收使用[批次精确清理](../../docs/test-resource-purge.md)：服务端登记归属，封存后按精确版本处理对象和删除标记，再移除专属登记与缓存。其他测试路径仍用相应的运维清理脚本验证版本化对象永久清除，不能用后台回收或生命周期代替。

启用测试前验证受限 RAM 权限，测试后先确认对象已永久清空，再清理专属登记。回滚二进制、批次登记迁移或撤销测试配置前须先清空这些资源和登记。
