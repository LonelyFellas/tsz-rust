# 临时测试资源

主记录和测试清理操作在前端仓库 [test-resource-isolation](https://github.com/LonelyFellas/tsz/blob/main/docs/features/test-resource-isolation/README.md)。

配置见根 `.env.example` 的 `TEST_RESOURCES_*`。未配置时不开放测试请求头；配置必须完整且至少有一个明确的管理员/用户 ID，两个身份域分别校验。测试 bucket 为 `tshb-test-assets`，root 为 `/temporary-tests`，不能由请求或环境变量改成普通目录。

支持语音试听、管理员音频、头像及认证材料图片。只在新建资源时需要有效测试头，持久化 key 自带批次与空间；读取和后台回收依该 key 选择测试存储。确认从测试暂存生成的文件时保留源批次，即使重试丢失请求头也不能写入普通目录。普通/测试和不同测试批次之间禁止复制；其余业务权限保持原规则。

同一批次的试听缓存独立于普通缓存和其他批次。对象存储仍按常规 delete 语义工作；版本化 bucket 的永久清理由运维清理脚本列举并删除精确版本和删除标记，不能用服务后台回收或生命周期代替。

启用测试前验证受限 RAM 权限，测试后先确认对象已永久清空，再清理专属登记。回滚二进制或撤销测试配置前也须先清空测试资源与登记，防止旧版本无法读取新的测试 key。没有数据库迁移。
